# 🌻 Calculator app

A calculator app capable of performing basic arithmetic operations, built using HTML, CSS and Javascript. This is my second project using this front-end stack. The calculations were implemented previously using the javascript `eval()` function as I wanted to focus on the CSS portion of the program but I have now implemented the proper logic and calculations.

## ✨ Technologies
- `HTML`
- `CSS`
- `Javascript`

## 🔥 Features
- Mouse hover and mouse click animations on the buttons
- Backspace button to correct mistakes
- Clear display button
- Negative sign toggle that changes display's value to opposite sign
- Immediate clearing of display when new number is entered after calculation
- Special themed pastel UI 🐮

## 💡 What I learned
- **Calculator logic:** I made the logic of this app similar to an actual calculator and found out that I had to take into account several cases.
- **Grid display:** I learned how to use the CSS grid layout system, and used it to rearrange my buttons and elongate my `=` key.
- **Error handling:** In an earlier version of this app, I placed the `eval()` function used to calculate output inside a try and catch block to handle exceptions.
- **setTimeout:** The `setTimeout()` function is called when the `eval()` function throws an error.
- **Anonymous functions:** `setTimeout()` led me to discover javascript's version of the lambda function; one I will definitely be using in the future.
- **Github Pages:** Discovering GitHub Pages helped me make my app more accessible as it requires no download or install.
